Build a modern, professional, visually impressive **Data Analyst Portfolio Website** for a data analyst who wants to showcase their analytical skills, business impact, projects, and technical expertise.

### Overall Design

Create a clean, premium analytics-focused design that feels professional but not boring. The visual identity should communicate **data, intelligence, insights, and business impact**.

Use a modern layout with:
- Clean typography
- Generous whitespace
- Subtle animations and transitions
- Data-inspired visual elements
- Professional dashboard/card aesthetics
- Responsive design for desktop, tablet, and mobile
- Light theme with a sophisticated dark navy/charcoal accent palette
- Subtle use of charts, grids, statistics, and data visualizations
- Avoid excessive gradients, glassmorphism, or overly flashy effects

The website should feel like a combination of a **professional portfolio + analytics dashboard**.

### Technical Requirements

Build the website using:

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**
- **Lucide React icons**
- **Recharts** for data visualizations

Use reusable components and clean project architecture.

Components should include things such as:

- Navbar
- Hero
- Stats
- About
- Skills
- ProjectCard
- ProjectDetails
- ChartCard
- ExperienceTimeline
- CertificationCard
- TestimonialCard
- ContactForm
- Footer

Keep the project data-driven so projects, skills, experience, certifications, and testimonials can be easily updated from TypeScript data objects rather than hardcoding everything into JSX.

### UX Requirements

Implement:

- Smooth scrolling
- Scroll reveal animations
- Hover effects
- Active navigation state
- Responsive mobile navigation
- Accessible buttons and links
- Keyboard accessibility
- Loading states where appropriate
- Form validation
- SEO metadata
- Open Graph metadata
- Proper semantic HTML

Animations should be subtle and professional. Do not over-animate the site.

### Responsive Design

The website must be fully responsive.

Desktop should feel like a premium professional portfolio.

Mobile should have:
- Clean navigation
- Stacked project cards
- Responsive charts
- Readable typography
- Touch-friendly buttons
- No horizontal scrolling

### SEO

Include:
- Professional page title
- Meta description
- Open Graph metadata
- Relevant keywords
- Semantic headings
- Proper image alt text
- Sitemap-ready structure

### Important

Do not make the website look like a generic developer portfolio.

The visual identity should specifically communicate **data analytics and business intelligence**.

The main storytelling should be:

**Problem → Data → Analysis → Insight → Recommendation → Business Impact**

Prioritize demonstrating how the analyst uses data to solve real-world business problems rather than simply listing technical skills.

Use realistic placeholder content and sample data where actual information is not provided, but structure everything so the real analyst can easily replace it later.

Build the site as a polished portfolio that would be credible when viewed by **recruiters, hiring managers, clients, and business stakeholders**.
